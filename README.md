# 🧮 Basic Calculator

A simple *calculator web page* built using *HTML* and *CSS* only.  
It performs *basic arithmetic operations* such as addition, subtraction, multiplication, and division — using a clean and responsive layout.

---

## 🚀 Features

- Performs basic arithmetic operations:  
  ➕ Addition  
  ➖ Subtraction  
  ✖ Multiplication  
  ➗ Division  
- Simple and user-friendly interface  
- Responsive design that adapts to different screen sizes  
- Pure HTML and CSS (no JavaScript)

---

## 🛠 Technologies Used

- *HTML5* – for structure  
- *CSS3* – for styling and layout
